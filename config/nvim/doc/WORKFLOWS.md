# Поведение редактора

## Сохранение и форматирование

Потеря фокуса сохраняет текущий изменённый файл. Go/Python/Lua форматируются
при сохранении; YAML/Bash форматируются вручную через `Space F`. Helm-шаблоны
не форматируются. Переключатели `Space u a` и `Space u f` позволяют временно
отключить autosave и format-on-save. Настройки по умолчанию остаются включёнными.

Отступы определяются по содержимому файла с учётом EditorConfig. Для Go, Python,
JSON, больших и специальных буферов автоматическое угадывание отключено.
YAML/Helm используют два пробела, Go — табы шириной четыре, JSON — два пробела.

Линтеры запускаются после открытия и сохранения. Несколько быстрых сохранений
объединяются в один запуск на каждый буфер. Python проверяется из корня Python-проекта,
Go — из своего модуля, даже если другая вкладка/папка является рабочей.
Проверка не меняет `:pwd` и не блокирует сохранение синхронным запуском Go-линтера.

## Проекты и терминал

Первый файл задаёт корень проекта для вкладки. Если до открытия файла явно
задать `:tcd`, выбор сохраняется. Открытие другого проекта в этой вкладке
не меняет рабочую папку автоматически. `Space f p` или новая вкладка переключают проект.
Путь файла справа внизу всегда вычисляется относительно проекта самого файла.

Терминал `Ctrl+\` открывается в рабочей папке. Команды активации venv/Poetry
не выполняются. Pyright не получает вычисленный конфигом `pythonPath`.
При необходимости Python настраивается явно в проекте; Python-тесты используют
`python3` из PATH. Активированное самим пользователем окружение может влиять на PATH.

## Сессии

`Space s s/l/d/x` сохраняет, загружает, удаляет или отсоединяет сессию.
Именованные активные сессии сохраняются при записи, выходе и периодически.
При загрузке восстанавливаются рабочие папки вкладок; автоматическое определение
проекта не перезаписывает их. Переключение сессий закрывает Snacks-терминалы
и их процессы. Несохранённая новая работа не превращается сама в именованную сессию.

## AI

NeoCodeium дополняет обычное LSP-дополнение. Tab принимает AI-подсказку,
затем переключает snippet, затем вставляет Tab. Файлы с секретами, kubeconfig,
облачными credentials, состоянием Terraform и gitignored-файлы исключены.
`Space u n` отключает AI в конкретном буфере. Headless-проверки AI-сервер не запускают.
