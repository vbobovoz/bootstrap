# Сопровождение

Править `config/nvim` в bootstrap, а не установленную копию. Применить:

```bash
bash install.sh --config nvim
```

В корне репы `bash tests/run.sh` проверяет установщик и отсутствие зависимости
от личных репозиториев исходного автора. `make -C config/nvim check` проверяет
объединённый конфиг: очередь Mason, корни проектов и линтеры, сессии, приватность AI,
DevOps-файлы и выделение стрелками. Быстрые проверки читают установленные checkouts
плагинов; writable data/state/cache изолированы и скачивания отключены.

Если новые плагины ещё не установлены, сначала применить конфиг и запустить Neovim.
Отдельная сетевая проверка `make -C config/nvim bootstrap-check` загружает плагины
в временное окружение. Полная Linux-проверка: `bash tests/ubuntu-container.sh 24.04`.

`:checkhealth custom`, `:checkhealth vim.lsp` и `:Mason` помогают найти отсутствующие
инструменты. Ошибка скачивания допускает новую попытку по FileType; после завершившегося
сбоя можно также вызвать `:MasonToolsInstall`. Очередь устанавливает инструменты
по языкам и не удаляет пакеты других языков.

Обновить плагины до новых версий: `:lua vim.pack.update()`.
После намеренного обновления перенести `nvim-pack-lock.json` в репу и проверить.
На другой машине после применения конфига синхронизировать закреплённые версии:
`:lua vim.pack.update(nil, { target = 'lockfile' })`, подтвердить и перезапустить.
