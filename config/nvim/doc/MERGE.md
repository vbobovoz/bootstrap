# Единый конфиг

Рабочий источник — `config/nvim` в репозитории `vbobovoz/bootstrap`.
`temp/nvim` использован только для сравнения и переноса изменений; он исключён
из Git и не читается установщиком. Отдельных clone/pull личного bootstrap или
Neovim-репозитория исходного автора нет.

## Что объединено

| Область | Итог |
|---|---|
| LSP/Mason | Общий каталог инструментов; последовательная установка по языкам; повтор после ошибки; запуск новых серверов после установки |
| DevOps | YAML/SchemaStore/yamllint, GitLab CI/Compose, Kubernetes, Helm/values, Dockerfile/Hadolint, Bash/ShellCheck/shfmt |
| Проекты | Кэш корней, сброс при изменении структуры, сохранение явно выбранной папки вкладки |
| Линтинг | Собственный адаптер golangci-lint v2, правильная папка каждого проекта, debounce с сохранением всех буферов, пропуск недоступных команд |
| Python-тесты | Общие правила поиска корня; интерпретатор из PATH, без поиска venv/Poetry |
| Сессии | Сохранение всех активных сессий перед переключением; корректное восстановление рабочих папок вкладок; прежний picker и список на старте |
| Git | Прежние знаки/blame плюс stage/reset/preview hunks и история файла/строки |
| Редактирование | Прежние Flash/autopairs/mini.ai/surround плюс mini.move/mini.jump и переключатели функций |
| AI | NeoCodeium вместо прежнего клиента Codeium; сохранены строгие исключения секретов, kubeconfig, Terraform state и gitignored-файлов; Sidekick загружается по требованию |
| Проверки | Изолированные quick checks, очередь Mason, линтеры, сессии, приватность, DevOps и выделение; отдельная сетевая проверка развёртывания |

## Сохранённые пользовательские решения

- Kanagawa Wave с фоном `#16161d`, цветные скобки и логотип NVIM.
- Ghostty 13 pt и переназначенные клавиши выделения/переключения панелей.
- Shift/Ctrl+Shift-выделение с копированием через `y`.
- Полный путь относительно проекта справа внизу, bufferline и lualine.
- Yazi на `Space o`, Flash на `Space j`, переключение буферов `H/L`.
- Автосохранение и форматирование Go/Python/Lua при сохранении включены.
- YAML/Bash форматируются вручную, Helm-шаблоны не форматируются.
- Автоактивация venv и собственный выбор Python-окружения не возвращены.

Одинаковые функции не включены дважды: mini.pairs не запускается рядом с
nvim-autopairs, mini.statusline/icons не заменяют существующие панели/иконки.
Связанные только с выбором Python-окружения ProjectTrust/PythonEnvRefresh
не перенесены. Меню переключателей перенесено на `Space u`, чтобы сохранить Yazi.

Сторонние open-source плагины и официальные релизы остаются внешними пакетами,
скачиваемыми при установке; это не зависимость от личных репозиториев автора.
MIT-лицензия и обязательная атрибуция сохранены.
